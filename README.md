# Spotify Global Chart Analytics Dashboard

A Streamlit web application to explore and analyze patterns, streams, and musical attributes of global chart-topping tracks.

## Features
- **Dataset Overview**: Interactive tabular display with expandable schema descriptions.
- **Key Performance Indicators (KPIs)**: Metrics for total tracks, total streams, average streams, and tempo (BPM).
- **Visualizations**:
  - Artist Streams (Bar Chart)
  - Streaming Trends Over Time (Line Chart)
  - Tempo (BPM) vs. Streams correlation (Scatter Plot)
- **Dynamic Filters**: Real-time filtering by Genre, BPM range, and Artist.

## Setup & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajveer812/PythonLab6.git
   cd PythonLab6
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the application:
   ```bash
   streamlit run app.py
   ```
